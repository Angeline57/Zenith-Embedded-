# Embedded System (Raspberry Pi)

- Interfaces with:
  - 9DOF inertial measurement unit (IMU)
  - Time-of-Flight distance sensor
- Performs:
  - Motion analysis
  - Fall detection
  - Bed exit and wandering detection
- Outputs **processed, high-level states**
  rather than raw sensor data
